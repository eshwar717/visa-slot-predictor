# 🎯 Visa Slot Release Prediction Engine

An interactive Streamlit dashboard designed to analyze historical visa slot drop patterns, predict high-probability release windows, and send real-time alerts.

---

## ✨ Features

* **🔮 Probability Predictor:** Select any day and time slot to calculate the likelihood of a slot release based on historical drop logs.
* **📊 Key Analytics:** View top release windows and total sample metrics at a glance.
* **🔄 Auto-Refreshing Interface:** Automatically polls and updates slot data every minute.
* **🔔 Live Telegram Alerts:** Sends instant push notifications when high drop probabilities are detected.

---

## 🛠️ Tech Stack

* **Frontend & Dashboard:** [Streamlit](https://streamlit.io/)
* **Data Processing:** Pandas, NumPy
* **Visualizations:** Plotly Express
* **Alerting:** Telegram Bot API (`requests`)
